# 08회차 문제 정의 기록

- **현상:** 관찰한 결과. 예: “값이 이상함” 대신 입력·기대값·실제값을 함께 기록.
- **원인:** 차이를 만든 Code 동작. Test로 확인하기 전에는 **가설**로 표시.
- **해결방안:** 같은 실패가 다시 생기지 않게 지킬 규칙과 변경 내용.
- 아래 블록을 문제마다 복사. 실패한 Test 개수와 근본 원인 개수를 구분.

## P01. 직접 붙인 문제 제목

| 단계 | 작성할 내용 | 내 기록 |
| --- | --- | --- |
| 현상 | 초기 상태, 입력 Byte, 실행 명령, 요구 결과, 실제 결과, Log 위치 | |
| 원인 가설 | 가능한 원인 A와 B. 두 가설의 결과가 달라지는 입력 또는 관찰 지점 | |
| 대조 Test | 한 번에 바꾼 조건 하나, 예상 결과, 실제 결과, 배제한 가설 | |
| 확정 원인 | File·함수·분기, 깨진 규칙, 근거가 되는 Datasheet 절 또는 요구 조건 | |
| 해결방안 | 보존해야 할 값·순서, 수정한 내용, 다른 대안보다 선택한 이유 | |
| 검증 | 같은 입력의 수정 전 / 수정 후, 직접 추가한 경계 Test, 미확인 사항 | |

- 세 문장으로 정리: “___ 조건에서 ___ 관찰.” / “___ 때문에 ___ 발생.” / “___ 변경 후 ___로 확인.”
