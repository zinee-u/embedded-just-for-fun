## 3. 초기화부터 UART까지 순서도

- 각 `[ ]`에 실제 함수 이름·Register 이름·값 기입. 실패한 단계가 발생하면 다음 단계와 UART 출력이 어떻게 되는지도 표시.

```text
전원·배선 조건 확인: [                              ]
  ↓
I2C0 Pin 설정: [SDA/SCL 위치·출력 기능·출력 방식] → [C 함수] ─ 실패 → [                  ]
  ↓ 성공
장치 식별: [어떤 Register를 읽고 무엇과 비교?       ] ─ 실패 → [            ]
  ↓ 성공
초기 설정: [첫 Write] → [다음 Write] → [준비 조건] ─ 실패 → [            ]
  ↓ 성공, 새 값이 안정됐다는 과제 전제
X축 읽기: [Register 위치 전달] → [두 Byte 수신]     ─ 실패 → [            ]
  ↓ 성공
값 변환: [Byte 결합] → [유효 Bit와 부호] → [UART용 값]
  ↓
UART 출력: [순번·값·상태를 담은 실제 한 줄] → [Log에서 확인할 값]
```
